# English_AI

# 🎙️ SpeakGenius AI — English Speaking Coach

> **Speak. Practice. Improve. Succeed.**

SpeakGenius AI is a modern, AI-powered English speaking practice platform designed to help learners improve their **speaking confidence, pronunciation, grammar, vocabulary, fluency, and communication skills** through personalized AI-powered practice.

The platform is designed for everyone from **complete beginners to advanced English speakers**, providing a personalized learning roadmap based on the user's current level, goals, challenges, interests, and available practice time.

---

## ✨ Features

### 🧠 AI-Powered Personalized Assessment

Before starting the learning journey, users complete a short assessment to understand their English-learning needs.

The assessment considers:

* Current English level
* Learning goals
* Speaking confidence
* Biggest communication difficulties
* Daily practice time
* Preferred learning style
* Areas of interest
* Native language
* Short speaking assessment

The collected information is used to create a personalized learning roadmap.

---

### 🗺️ Personalized Learning Roadmap

SpeakGenius AI creates a personalized learning plan based on the learner's:

* Current proficiency
* Target proficiency
* Learning objective
* Weak areas
* Daily available time
* Speaking performance

Example roadmap:

```text
Monday     → Pronunciation Practice
Tuesday    → Grammar Practice
Wednesday  → Vocabulary
Thursday   → AI Conversation
Friday     → Mock Interview
Saturday   → Role Play
Sunday     → Weekly Review
```

The roadmap adapts as the learner progresses.

## ✍️ AI Grammar Correction

The AI analyzes spoken or typed English and identifies grammatical mistakes.

Example:

**You said:**

> He go to school yesterday.

**AI correction:**

> He went to school yesterday.

**Explanation:**

The sentence refers to a completed action in the past, so the verb should use the past tense.

# 🔐 Environment Variables

Create a `.env` file for local development.

Example:

```env
AI_API_KEY=your_api_key
SUPABASE_URL=your_supabase_url
SUPABASE_ANON_KEY=your_supabase_anon_key
```

Never commit real API keys to GitHub.

Add `.env` to `.gitignore`.

# 🚀 Getting Started

## 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd speakgenius-ai
```

## 2. Install dependencies

```bash
npm install
```

If a Python backend is included:

```bash
pip install -r requirements.txt
```

## 3. Configure environment variables

Create:

```text
.env
```

Add the required API keys and database configuration.

## 4. Start the frontend

```bash
npm run dev
```

## 5. Start the backend

For FastAPI:

```bash
uvicorn main:app --reload
```
